# Onboarding Docs Nits: CLI Redirect, Canonical Package Name, llms.txt Ordering, Signup Alignment

**ADW ID:** e6a00177
**Date:** 2026-06-04
**Plan-Spec:** specs/adw/issue-192-adw-e6a00177-onboarding-docs-nits-plan.md

## Overview

Fixes a bundle of four independent onboarding/documentation nits (F1, F2, F6, F7) surfaced by dogfooding the live Mnemom docs site. Each erodes the first five minutes of an agent's or human's integration experience — a dead CLI link, an ambiguous Python package name, an `llms.txt` index that buries onboarding paths, and signup docs that imply fields the real form does not have. All changes are surgical config-and-prose edits within the `docs` (Mintlify) repo; no new pages, dependencies, or build steps.

## What Was Built

- **F1 — `/quickstart/cli` redirect:** the dead `docs.mnemom.ai/quickstart/cli` URL now redirects to the canonical CLI reference at `/gateway/cli`.
- **F6 — `llms.txt` onboarding entry point:** the "Getting Started" navigation tab was promoted to second position (immediately after "For AI Agents"), lifting the `/quickstart/*` pages near the top of the Mintlify-generated `/llms.txt` index.
- **F2 — Canonical Python package name:** an authoritative callout in `introduction.mdx` pins the only valid package names and warns against the stray `mnemom-aip` name.
- **F7 — Signup docs alignment:** the onboarding entry point now states the real signup form shape (email + password only), with no company field and no CRM-sync claim, linking to the generated Sign up reference.

## Technical Implementation

### Files Modified

- `docs.json`: added the `/quickstart/cli` → `/gateway/cli` redirect entry; reordered `navigation.tabs` to move the "Getting Started" tab ahead of "Documentation".
- `introduction.mdx`: added a `<Note>` callout under the SDK packages table pinning the canonical PyPI/npm package names.
- `quickstart/overview.mdx`: added "Create your account" and "Install and authenticate" sections describing the real email + password signup form.

### Key Changes

- **Redirect targets a concrete page.** The F1 redirect points at `/gateway/cli` (a real `gateway/cli.mdx` page) rather than `/smoltbot/cli` (itself only a redirect source), avoiding a redirect chain and satisfying `scripts/check-redirects.mjs`, which resolves non-wildcard destinations against existing pages.
- **`llms.txt` ordering is driven by nav order, not hand-editing.** `/llms.txt` is auto-generated by Mintlify from the `docs.json` navigation tree, so promoting the "Getting Started" tab is the only repo-controllable lever to surface onboarding paths near the top. No page was added, removed, renamed, or orphaned.
- **Single source of truth for the package name.** The callout standardizes on `agent-integrity-proto` (AIP) and `agent-alignment-proto` (AAP) — names already used consistently across the repo — and explicitly states `mnemom-aip` is not a real package.
- **Signup note stays prose-only.** F7 links to the existing `api-reference/endpoint/post-auth-sign-up` reference instead of hand-writing a `curl https://api.mnemom.ai/...` block, so the doc-as-spec validator (`check-doc-examples.mjs`) is not triggered and the request contract is not duplicated.

## How to Use

1. **Verify the CLI redirect:** navigate to `docs.mnemom.ai/quickstart/cli` — it now lands on the canonical CLI reference at `/gateway/cli`.
2. **Find onboarding in `llms.txt`:** open `docs.mnemom.ai/llms.txt` — the `/quickstart/*` onboarding paths now appear near the top, just below the "For AI Agents" entry.
3. **Install the correct package:** follow the callout in the introduction — `pip install agent-integrity-proto` (AIP) or `agent-alignment-proto` (AAP); never `mnemom-aip`.
4. **Create an account:** from the quickstart overview, sign up with email + password only; a personal organization is auto-provisioned at signup.

## Configuration

No configuration, environment variables, or settings changes. `docs.json` remains the routing and navigation config contract.

## Testing

Run from the repo/worktree root — each command must exit cleanly:

- `npm run check:redirects` — **lint verb.** Validates the redirect table, including the new `/quickstart/cli` → `/gateway/cli` entry and the `/` → `/introduction` root invariant.
- `echo "(no typecheck for MDX docs)"` — **typecheck verb** (no-op; MDX has no static type step).
- `npm ci && npm run check:doc-examples` — **test verb.** Doc-as-spec validator: confirms no malformed `api.mnemom.ai` curl example was introduced.
- `echo "(Mintlify-hosted build; validated by CI)"` — **build verb** (no-op; the site is Mintlify-hosted).
- `mintlify broken-links` — the required **"Validate Mintlify Docs"** check. Must report zero broken internal links after the nav reorder and redirect addition.
- `grep -rn "mnemom-aip" --include='*.mdx' --include='*.md' --include='*.txt' --include='*.json' . | grep -v node_modules` — must print nothing (F2 assertion).

There is no application code or E2E harness in this repo; the "tests" are the deterministic doc gates above.
