# XFD security architecture (retired)

**XFD** was the internal engineering codename for the threat-detection architecture surrounding Mnemom agents. The customer-facing canonical surface is now [Safe House](/concepts/safe-house) — the per-customer perimeter with four checkpoints (front door, back door, inside.autonomy, inside.integrity), each independently set to one of four enforcement modes (`off`, `observe`, `nudge`, `enforce`).

The cross-tenant defensive network above Safe House is [AEGIS](/concepts/aegis) — the L0-L5 [Protection Network](/concepts/protection-network) that aggregates signals across customers, signs cross-tenant [Managed Rules](/concepts/managed-rules), and publishes [IoCs](/concepts/iocs) + [advisories](/concepts/advisories).
