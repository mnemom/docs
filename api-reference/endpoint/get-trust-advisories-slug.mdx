---
title: "Fetch a published advisory by slug"
description: "Returns the canonical advisory record for {slug}."
openapi: "GET /trust/advisories/{slug}"
---

<Note>
**Read-only today.** This endpoint only supports `GET` — there is no public
API to create, edit, or delete advisories. Requests share the global
per-IP gateway limit applied to every `/v1/*` route: 100 requests/minute
per IP; there is no additional limit specific to this endpoint.
</Note>
