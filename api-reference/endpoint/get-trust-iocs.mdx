<Note>
**Read-only today.** `GET /trust/iocs` is the only method on this path —
there is no API to submit, modify, or remove indicators. Requests share the
global per-IP gateway limit applied to every `/v1/*` route: 100
requests/minute per IP; there is no additional limit specific to this
endpoint. The STIX 2.1 bundle is not cryptographically signed today —
signing is planned but not yet available.
</Note>
