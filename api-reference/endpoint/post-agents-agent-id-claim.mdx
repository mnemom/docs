<Warning>
**Legacy endpoint.** Kept only for agents that pre-date [`POST /v1/agents`](/api-reference/endpoint/post-agents). The modern flow registers, claims, and links in a single authenticated `POST /v1/agents` call — there is no separate claim step. New code should not use this endpoint. See the [Registration section in Agent identity](/concepts/agent-identity#registration) for the canonical flow.
</Warning>
