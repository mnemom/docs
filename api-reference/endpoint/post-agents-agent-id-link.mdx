title: "Link claimed agent to authenticated user (legacy)"
description: "Link a claimed agent to the authenticated user (legacy flow; prefer POST /agents for new integrations)."
openapi: "POST /agents/{agent_id}/link"
---

<Warning>
**Legacy endpoint.** Kept only for agents that pre-date [`POST /v1/agents`](/api-reference/endpoint/post-agents). The modern flow registers, claims, and links in a single authenticated `POST /v1/agents` call — the auth principal on that request is recorded as `claimed_by`/`user_id` inline. New code should not use this endpoint. See the [Registration section in Agent identity](/concepts/agent-identity#registration) for the canonical flow.
</Warning>
