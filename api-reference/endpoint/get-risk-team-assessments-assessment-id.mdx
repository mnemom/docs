---
title: "Get a single team risk assessment by id"
openapi: "GET /risk/team-assessments/{assessment_id}"
---

<Note>
**Authentication required.** Pass your Bearer token (`Authorization: Bearer <token>`) or API key (`X-Mnemom-Api-Key: <key>`). Results are account-scoped — a valid token from a different account returns `404` rather than `403` to avoid leaking resource existence. See [Authorization model](/concepts/risk-assessment#authorization-model).
</Note>
