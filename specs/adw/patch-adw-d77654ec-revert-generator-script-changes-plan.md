## Problem / Objective
**Original Spec:** /home/runner/work/docs/docs/agents/d77654ec/plan/issue-232-adw-d77654ec-sync-openapi-freshness-plan.md
**Issue:** `scripts/generate-api-reference.mjs` was modified in two out-of-scope ways: (1) `'OAuth'` was inserted into `GROUP_ORDER` (line ~48), and (2) the single `docs.navigation.tabs.find(...)` call was replaced with a three-fallback chain that also handles `docs.navigation.languages` (lines ~169-174). These are source changes to the generator itself. The sync PR is authorized only to commit outputs of running the scripts as-is — script fixes require their own PR with justification. Consequence: because `docs.json` uses `navigation.languages` and origin/main's script only reads `navigation.tabs`, origin/main's script would crash if run today. Therefore the 8 new `.mdx` stubs and the `docs.json` nav additions — all produced by the modified script — cannot be retained; they are outputs of an unauthorized script and must be reverted alongside the script itself.
**Solution:** Restore `scripts/generate-api-reference.mjs` to its `origin/main` state, then revert the docs.json nav additions and the 8 new endpoint stubs back to `origin/main`, leaving only `api-reference/openapi.json` (the legitimate `sync-openapi.mjs` output) in the diff.
