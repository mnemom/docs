# Choisissez votre chemin

<Note>
  Ces démarrages rapides sont disponibles en [espagnol (Español)](/es/quickstart/overview) et en [français (Français)](/fr/quickstart/overview) — six pages par langue ont été traduites.

## Créer votre compte

Inscrivez-vous sur [mnemom.ai/claim](https://mnemom.ai/claim) avec votre **e-mail et mot de passe** — c'est le formulaire complet. Pas de champ entreprise, pas de synchronisation CRM. À l'inscription, une [organisation personnelle](/concepts/personal-organization) est provisionnée automatiquement et liée à votre compte. Consultez la [référence d'inscription](/api-reference/endpoint/post-auth-sign-up) pour l'équivalent API.

## Choisir un chemin

<Tip>
**Invité à sparrer dans le Dojo ? Une commande, zéro installation.** Si quelqu'un vous a remis un jeton d'invitation `/try-me`, exécutez `npx @mnemom/mnemom@latest try-me <token>` — cela déroule tout le flux de bout en bout (né → revendiqué → déclaré → en sparring), sans configuration nécessaire. Utilisez `@latest` pour qu'une machine qui revient ne réutilise pas un build en cache obsolète. Un équivalent Python, `uvx mnemom try-me <token>`, arrive bientôt.
</Tip>

Quatre façons d'ajouter Mnemom à vos agents IA — chaque page ci-dessous est un guide complet et autonome pour son chemin.

<Note>
Chaque agent Mnemom possède **deux cartes** — une [carte d'alignement](/concepts/agent-cards) (qui est l'agent et ce qu'il est autorisé à faire) et une [carte de protection](/concepts/protection-card) (comment il est défendu). Les deux se composent depuis la portée plateforme > organisation > agent. Quel que soit le chemin choisi ci-dessous, vous finirez par créer ces deux cartes en YAML ; le [guide de gestion des cartes](/guides/card-management) et le [guide de gestion des cartes de protection](/guides/safe-house-config) couvrent le cycle de vie.
</Note>

## Comparaison

| Fonctionnalité | Gateway | SDK Direct | Auto-hébergé | Safe House seul |
|---------|---------|------------|-------------|------------------|
| **Temps de configuration** | 5 minutes | 30 minutes | Plus long (Docker/Kubernetes) | 5 minutes |
| **Modifications de code** | Aucune | Modérées | Aucune (même code de passerelle) | Aucune |
| **Traces AAP** | Automatiques | Manuelles | Automatiques | Non incluses |
| **Intégrité AIP** | Automatique | Manuelle | Automatique | Non incluse |
| **Tableau de bord** | Inclus | Inclus | Auto-hébergé | Inclus |
| **Résidence des données** | Cloud Mnemom | Cloud Mnemom | Votre infrastructure | Cloud Mnemom |
| **Modes d'application** | observe / nudge / enforce | Vous implémentez | observe / nudge / enforce | observe / nudge / enforce |
| **Gouvernance des politiques** | [CLPI](/concepts/clpi) intégré | Vous configurez | [CLPI](/concepts/clpi) intégré | Non incluse |
| **Multi-fournisseur** | Anthropic, OpenAI, Gemini | N'importe lequel (vous extrayez le raisonnement) | Anthropic, OpenAI, Gemini | Identique à votre passerelle existante |
| **Coût** | Basé sur l'utilisation | Basé sur l'utilisation | Licence Enterprise + votre infrastructure | Basé sur l'utilisation |

## Que dois-je choisir ?

<AccordionGroup>
  <Accordion title="Je veux le chemin le plus rapide vers la conformité">
    Utilisez la **Mnemom Gateway**. Installez la CLI, exécutez `mnemom login`, pointez votre client LLM vers `gateway.mnemom.ai`, et vos appels API sont automatiquement tracés et vérifiés. Aucune modification de code requise.
  </Accordion>
  <Accordion title="J'ai besoin d'un contrôle total sur le traçage et la vérification">
    Utilisez le **SDK Direct**. Vous définissez exactement quand les traces sont générées, comment les vérifications d'intégrité s'exécutent, et ce qui se passe en cas de violations. Idéal pour les frameworks d'agents personnalisés ou lorsque vous devez intégrer des systèmes d'observabilité existants.
  </Accordion>
  <Accordion title="Mes données ne peuvent pas quitter mon infrastructure">
    Utilisez l'**Auto-hébergement**. Déployez le même code de passerelle sur votre propre infrastructure Docker ou Kubernetes — même traçage automatique et mêmes modes d'application, mais vous contrôlez tout. Nécessite une licence Enterprise.
  </Accordion>
  <Accordion title="Je route déjà via la passerelle et je veux juste le filtrage des menaces">
    Utilisez la **Protection Safe House**. Elle configure la même carte de protection que la passerelle lit déjà — pas de migration, activez simplement le mode `observe` et c'est parti.
  </Accordion>
  <Accordion title="Je construis un système agent-à-agent">
    Commencez avec le **SDK Direct** pour la vérification de cohérence des valeurs entre agents. Vous pouvez combiner cela avec la passerelle pour le traçage, ou gérer les traces vous-même. Consultez le [guide d'intégration A2A](/protocols/aap/a2a-integration) pour les détails.
  </Accordion>
</AccordionGroup>
