# Choisissez votre chemin

## Créer votre compte

Inscrivez-vous sur [mnemom.ai/claim](https://mnemom.ai/claim) avec votre **adresse e-mail et mot de passe** — c'est tout. Pas de champ entreprise, pas de synchronisation CRM. À l'inscription, une [organisation personnelle](/concepts/personal-organization) est provisionnée automatiquement et liée à votre compte. Consultez la [référence d'inscription](/api-reference/endpoint/post-auth-sign-up) pour l'équivalent API.

## Installer et s'authentifier

Le chemin le plus rapide — installez la CLI et routez votre première requête :

```bash
npm install -g @mnemom/mnemom && mnemom login
```

Cela authentifie la CLI auprès de votre compte Mnemom et configure le traçage local vers `gateway.mnemom.ai`. Votre agent est enregistré automatiquement lors du premier routage d'une requête via la passerelle. Aucune modification de code, pas de configuration de clé API. Vous revendiquerez l'agent créé automatiquement une fois pour le lier à votre compte — consultez le [démarrage rapide Gateway](/fr/quickstart/gateway). Continuez à lire si vous avez besoin d'une intégration plus approfondie.

Il existe trois façons d'ajouter la vérification d'alignement et la vérification d'intégrité à vos agents IA. Choisissez celle qui convient à vos contraintes.

<Note>
Chaque agent Mnemom possède **deux cartes** — une [carte d'alignement](/concepts/agent-cards) (qui est l'agent et ce qu'il est autorisé à faire) et une [carte de protection](/concepts/protection-card) (comment il est défendu). Les deux se composent de la portée plateforme &gt; organisation &gt; agent. Quelle que soit la voie choisie ci-dessous, vous finirez par créer ces deux cartes en YAML ; le [guide de gestion des cartes](/guides/card-management) et le [guide de gestion des cartes de protection](/guides/safe-house-config) couvrent le cycle de vie.
</Note>

## Comparaison

| Fonctionnalité | Gateway | SDK Direct | Auto-hébergé |
|----------------|---------|------------|--------------|
| **Temps de configuration** | 5 minutes | 30 minutes | 2 heures |
| **Modifications de code** | Aucune | Modérées | Modérées |
| **Traces AAP** | Automatiques | Manuelles | Automatiques |
| **Intégrité AIP** | Automatique | Manuelle | Automatique |
| **Tableau de bord** | Inclus | Inclus | Auto-hébergé |
| **Résidence des données** | Cloud Mnemom | Cloud Mnemom | Votre infrastructure |
| **Modes d'application** | observe / nudge / enforce | Vous implémentez | observe / nudge / enforce |
| **Gouvernance des politiques** | [CLPI](/concepts/clpi) intégré | Vous configurez | [CLPI](/concepts/clpi) intégré |
| **Multi-fournisseur** | Anthropic, OpenAI, Gemini | N'importe lequel | Anthropic, OpenAI, Gemini |
| **Coût** | Basé sur l'utilisation | Basé sur l'utilisation | Gratuit (vous payez l'infrastructure) |

## Que dois-je choisir ?

<AccordionGroup>
  <Accordion title="Je veux le chemin le plus rapide vers la conformité">
    Utilisez la **Mnemom Gateway**. Installez la CLI, exécutez `mnemom login`, pointez votre client LLM vers `gateway.mnemom.ai`, et vos appels API sont automatiquement tracés et vérifiés. Aucune modification de code requise.
  </Accordion>
  <Accordion title="J'ai besoin d'un contrôle total sur le traçage et la vérification">
    Utilisez le **SDK Direct**. Vous définissez exactement quand les traces sont générées, comment les vérifications d'intégrité s'exécutent, et ce qui se passe en cas de violations. Idéal pour les frameworks d'agents personnalisés ou lorsque vous devez intégrer des systèmes d'observabilité existants.
  </Accordion>
  <Accordion title="Mes données ne peuvent pas quitter mon infrastructure">
    Utilisez l'**Auto-hébergement**. Déployez la stack Mnemom Gateway (Cloudflare Workers + Supabase) sur vos propres comptes. Toutes les données restent dans votre infrastructure. Même traçage automatique que la passerelle, mais vous contrôlez tout.
  </Accordion>
  <Accordion title="Je construis un système agent-à-agent">
    Commencez avec le **SDK Direct** pour la vérification de cohérence des valeurs entre agents. Vous pouvez combiner cela avec la passerelle pour le traçage, ou gérer les traces vous-même. Consultez le [guide d'intégration A2A](/protocols/aap/a2a-integration) pour les détails.
  </Accordion>
</AccordionGroup>
