# Elige tu camino

## Crear tu cuenta

Regístrate en [mnemom.ai/claim](https://mnemom.ai/claim) con tu **correo electrónico y contraseña** — eso es todo. Sin campo de empresa, sin sincronización CRM. Al registrarte, se aprovisiona automáticamente una [organización personal](/concepts/personal-organization) vinculada a tu cuenta. Consulta la [referencia de registro](/api-reference/endpoint/post-auth-sign-up) para el equivalente en API.

## Instalar y autenticarse

El camino más rápido — instala la CLI y enruta tu primera solicitud:

```bash
npm install -g @mnemom/mnemom && mnemom login
```

Esto autentica la CLI con tu cuenta de Mnemom y configura el rastreo local hacia `gateway.mnemom.ai`. Tu agente se registra automáticamente la primera vez que enrutas una solicitud a través de la pasarela. Sin cambios de código, sin configuración de claves API. Reclamarás el agente creado automáticamente una vez para vincularlo a tu cuenta — consulta el [inicio rápido de Gateway](/es/quickstart/gateway). Continúa leyendo si necesitas una integración más profunda.

Hay tres formas de agregar verificación de alineamiento y comprobación de integridad a tus agentes de IA. Elige la que se adapte a tus restricciones.

<Note>
Cada agente de Mnemom tiene **dos tarjetas** — una [tarjeta de alineamiento](/concepts/agent-cards) (quién es el agente y qué tiene permitido hacer) y una [tarjeta de protección](/concepts/protection-card) (cómo se defiende). Ambas se componen desde el ámbito plataforma &gt; organización &gt; agente. Cualquiera que sea el camino que elijas a continuación, terminarás creando estas dos tarjetas en YAML; la [guía de gestión de tarjetas](/guides/card-management) y la [guía de gestión de tarjetas de protección](/guides/safe-house-config) cubren el ciclo de vida.
</Note>

## Comparación

| Característica | Gateway | SDK Directo | Auto-alojado |
|----------------|---------|-------------|--------------|
| **Tiempo de configuración** | 5 minutos | 30 minutos | 2 horas |
| **Cambios de código** | Ninguno | Moderados | Moderados |
| **Trazas AAP** | Automáticas | Manuales | Automáticas |
| **Integridad AIP** | Automática | Manual | Automática |
| **Panel de control** | Incluido | Incluido | Auto-alojado |
| **Residencia de datos** | Nube de Mnemom | Nube de Mnemom | Tu infraestructura |
| **Modos de aplicación** | observe / nudge / enforce | Tú implementas | observe / nudge / enforce |
| **Gobernanza de políticas** | [CLPI](/concepts/clpi) integrado | Tú configuras | [CLPI](/concepts/clpi) integrado |
| **Multi-proveedor** | Anthropic, OpenAI, Gemini | Cualquiera | Anthropic, OpenAI, Gemini |
| **Costo** | Basado en uso | Basado en uso | Gratis (tú pagas la infraestructura) |

## ¿Cuál debo elegir?

<AccordionGroup>
  <Accordion title="Quiero el camino más rápido hacia el cumplimiento">
    Usa **Mnemom Gateway**. Instala la CLI, ejecuta `mnemom login`, apunta tu cliente LLM a `gateway.mnemom.ai`, y tus llamadas API se rastrean y verifican automáticamente. No se requieren cambios de código.
  </Accordion>
  <Accordion title="Necesito control total sobre el rastreo y la verificación">
    Usa **SDK Directo**. Defines exactamente cuándo se generan las trazas, cómo se ejecutan las comprobaciones de integridad y qué sucede ante las violaciones. Ideal para frameworks de agentes personalizados o cuando necesitas integrarte con sistemas de observabilidad existentes.
  </Accordion>
  <Accordion title="Mis datos no pueden salir de mi infraestructura">
    Usa el **Auto-alojamiento**. Despliega el stack de Mnemom Gateway (Cloudflare Workers + Supabase) en tus propias cuentas. Todos los datos permanecen en tu infraestructura. El mismo rastreo automático que la pasarela, pero tú controlas todo.
  </Accordion>
  <Accordion title="Estoy construyendo un sistema agente a agente">
    Comienza con **SDK Directo** para la verificación de coherencia de valores entre agentes. Puedes combinarlo con la pasarela para el rastreo, o manejar las trazas tú mismo. Consulta la [guía de integración A2A](/protocols/aap/a2a-integration) para más detalles.
  </Accordion>
</AccordionGroup>
